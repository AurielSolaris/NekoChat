# NekoChat palette

"One Dark, but cozy." Code tokens live in `app/ui/com/nekochat/ui/theme/Glass.kt` (`object Neko`).

| Token | Hex | Use |
|-------|-----|-----|
| Background | `#282C34` | App background |
| Background Deep | `#21252B` | Backdrop gradient ends, launcher tile |
| Surface | `#2C313C` | Glass base (translucent) |
| Surface Elevated | `#323842` | Elevated glass base (translucent) |
| Border | `#3A404C` | Hairline borders |
| Primary Pink | `#F4A7B9` | Primary actions, selection, focus, mascot body |
| Light Pink | `#F8C7D2` | Pressed/hover accents |
| Soft Pink | `#EFA0B5` | Subtle shading, paw beans |
| Pink Highlight | `#FFD6DF` | Inner ears, highlights |
| Cream | `#FFF7F0` | Mascot paws and belly |
| Gold | `#D9A441` | Mascot bell only (never competes with pink) |
| Text Primary | `#F0F0F0` | Body text |
| Text Secondary | `#ABB2BF` | Secondary text |
| Text Muted | `#7F848E` | Hints, metadata (≥ 12sp) |
| Success | `#98C379` | Positive status |
| Warning | `#E5C07B` | Warnings |
| Error | `#E06C75` | Errors, mascot collar |
| Info | `#61AFEF` | Informational accents |
| On Pink | `#282C34` | Text/icons on Primary Pink (contrast ≈ 8:1) |

Contrast on `#282C34`: Text Primary ≈ 12.5:1, Text Secondary ≈ 7:1, Text Muted ≈ 3.8:1
(metadata only), Primary Pink ≈ 8:1.
